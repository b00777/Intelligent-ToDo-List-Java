# Intelligent To-Do List with Prioritization

## 📌 Overview

This project is a Java-based task management application designed to help users organize and prioritize tasks efficiently.

Unlike traditional static to-do lists, the system focuses on smart task prioritization using urgency and importance-based logic.

The application supports:
- Task creation
- Task updating
- Task deletion
- Priority categorization

The project also demonstrates the implementation of object-oriented programming concepts and modular design principles using Java.

---

## 🚀 Features

- Add new tasks
- Update existing tasks
- Delete completed tasks
- Assign priority levels
- Categorize tasks based on urgency
- Simple and responsive task management flow
